# DAEGU:IDE

대구 거주 외국인을 위한 AI 금융생활 가이드 프로토타입입니다.

금융·행정 문서를 촬영하거나 업로드하면 핵심 금액, 날짜, 주의 조건을 쉬운 언어로 설명하고 금융 일정, 피싱 위험 확인, 상담카드, 문서 기반 질문 기능으로 연결하는 서비스 흐름을 구현했습니다.

## 주요 기능

- 한국어·영어·중국어·베트남어 화면 전환
- 금융문서 업로드 및 샘플 분석
- 핵심 금액·날짜·공제 내역 구조화
- 금융 캘린더와 납부·입금 일정 표시
- 의심 문자 피싱 위험도 분석
- 한국어 상담카드 생성 및 복사
- 문서 내용에 관한 AI 질문 시연
- 모바일·데스크톱 반응형 디자인

## 실행 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 정적 웹 서버를 사용하는 경우 저장소 루트에서 아래 명령을 실행할 수 있습니다.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다.

## 프로토타입 범위

현재 버전은 공모전 시연을 위한 인터랙티브 프로토타입입니다. 실제 OCR, 생성형 AI, 금융기관 API 및 개인정보 저장 기능은 연결되어 있지 않습니다.
